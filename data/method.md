# 方法

野榜每周一发布一期，两张榜：技能榜、应用榜。这页写的是怎么排的，每一期的原始数据和排名脚本都在 [仓库](https://github.com/0xrelander/yebang) 里，任何人都能自己跑一遍核对。

## 排什么

- **技能榜**：独立开发者做的 agent 技能 / 插件。agent 是能替人干活的 AI 程序，技能是装给它的一项本事。
- **应用榜**：普通人做出来、搜不到但好用的 AI 应用，包括独立网站、App，和挂在平台商店里的智能体。

## 不排什么

- 大厂和平台官方出品的技能 / 应用。
- 中转、代理、倒卖 API 额度的服务，以及任何要绕过平台规则才能用的东西。
- 没有独立可用形态的东西：只有介绍文章、只有一个群，不算。
- 应用榜里发布当天打不开的，不排。

## 数据从哪来

只采公开的、企业或项目层面的数据，个人信息一条不碰。本期来源：

| 来源 | 采什么 | 数值 |
|---|---|---|
| SkillHub（腾讯 WorkBuddy 技能市场） | 社区技能 | 下载量、star |
| ClawHub（OpenClaw 技能市场） | 名字或描述含中文的技能 | 下载量、安装量、star |
| 虾评Skill | 全部技能 | 下载量、评分、评测数 |
| skills.sh（Claude Code / Codex / Cursor 等通用技能目录） | 首页榜 + 按中文平台词（小红书、微信、抖音、飞书等）搜到的技能 | 近 8 周每周安装量、累计安装量 |
| 扣子商店 | 非官方、非企业号的智能体和应用 | 用户数、对话数、热度 |
| V2EX 分享创造 | 近 30 天带 AI 关键词的「我做了一个」帖 | 浏览数、回复数 |
| 投稿 | 任何人投来的技能 / 应用 | 投稿人给的可核数据 |

拿不到公开数字的来源这期没进：小红书、即刻、钉钉和飞书的应用市场、Product Hunt 票数。拿到了就加。

## 怎么排

1. **合并**：同一个技能在几个来源都出现，按名字归一后合并成一条，算一条。
2. **来源内归一**：每个来源单独算。归一分 = log10(1 + 该条数值) ÷ log10(1 + 该来源候选中的最大数值)，范围 0 到 1。取对数是因为下载量这种数字差几个量级，不取对数的话第一名之外全是 0。
3. **野榜分** = 各来源归一分里的最高值，加「每多出现在一个来源 +0.1」，最多加 0.3。跨平台都有人用，是比单平台数字大更硬的信号。
4. 按野榜分排序，同分看原始数值。
5. 应用榜在发布当天逐条打开一次，打不开的拿掉。

**创刊号按累计数值排**。从第 2 期起主排本周增量（本期的数据已经留了快照），累计量当参考。这样新东西有机会上来，老东西不会永远霸榜。

## 什么时候更新

每周一发布，数据截至发布前一天 24:00 北京时间。采集、合并、打分、出页、出图全由脚本跑，人只看最后十条和纠错。

## 认领与纠错

- 榜上的东西是你做的：[认领](https://github.com/0xrelander/yebang/issues/new?template=claim.yml)，署名和介绍改成你要的写法。
- 数据或信息有错：同一个表单选「纠错」，给正确数据的来源。发布后 7 天内收到的当期改并注明，超过 7 天的下一期修正。
- 不想上榜：同一个表单选「下榜」，照办。

## 已知的坑

- 各平台的「下载量」口径不一样，有的算自动安装，有的只算人点的。所以不跨来源直接比数字，只在来源内归一。
- 境外技能目录（ClawHub、skills.sh）只收中文相关的条目，会漏掉中国作者用英文发布的技能。认领或投稿可以补上。
- 创刊号的应用榜来源还少，扣子商店和 V2EX 两个口子，投稿多了会好起来。

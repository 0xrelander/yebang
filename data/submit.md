# 投稿 / 认领

野榜不接广告，不收费收录。进库只看一件事：方法页里写明的四道门。

## 我做了个网站，想被收录

- 投稿入口：[GitHub 投稿表单](https://github.com/0xrelander/yebang/issues/new?template=submit.yml)，填名字、网址、一句话、署名，一分钟。
- 投来的网站下一期和所有候选一起过四道门：是独立网站、作者是个人、当天打得开、有可操作界面。过了就进搜索库，不保证进精选。
- 给能直接打开的网址。只有仓库页、只有一篇介绍、只有一个群的，不算。
- 我们只采**公开的、项目层面的**数据：star、公开帖子的回复数、页面标题。不采任何个人信息。

## 库里的是我做的

- [认领表单](https://github.com/0xrelander/yebang/issues/new?template=claim.yml)：给一个能证明作者身份的链接（仓库、主页、作者页），我们把署名和介绍改成你要的写法。
- 认领后，这条在库里和后面每一期都按你认领的署名显示。

## 信息有错 / 我不想被收录

- 同一个表单，选「纠错」或「下榜」。纠错给正确信息的来源，下榜说一句原因就行。
- 发布后 7 天内收到的纠错，在当期页面直接改并注明；超过 7 天的，在下一期修正。

## 什么不收

- 大厂和机构出品的网站（它们不缺人看）。
- 中转 / 代理 / 倒卖 API 额度的服务，任何需要绕过平台规则才能用的东西。
- 没有独立可用形态的东西：只有一个仓库、一篇介绍文章、一个群，不算。

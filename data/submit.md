# 投稿 / 认领

野榜不接广告，不收费上榜。上榜只看一件事：方法页里写明的公开数据。

## 我做了个东西，想上榜

- 投稿入口：[GitHub 投稿表单](https://github.com/0xrelander/yebang/issues/new?template=submit.yml)，填名字、链接、一句话、署名，一分钟。
- 投稿不保证上榜。投来的东西进候选池，下一期按同一套公开方法和所有候选一起排。
- 技能类：给能安装的地址（技能市场页 / GitHub 仓）。应用类：给能直接打开的网址。打不开的不排。
- 我们只采**公开的、企业或项目层面的**数据：安装量、star、公开帖子的回复数。不采任何个人信息。

## 榜上的是我做的

- [认领表单](https://github.com/0xrelander/yebang/issues/new?template=claim.yml)：给一个能证明作者身份的链接（仓库、主页、技能市场作者页），我们把署名和介绍改成你要的写法。
- 认领后，这条在后面每一期都按你认领的署名显示。

## 榜上的信息有错 / 我不想上榜

- 同一个表单，选「纠错」或「下榜」。纠错给正确数据的来源，下榜说一句原因就行。
- 发布后 7 天内收到的纠错，在当期页面直接改并注明；超过 7 天的，在下一期修正。

## 什么不收

- 大厂官方出品的技能 / 应用（它们不缺人看）。
- 中转 / 代理 / 倒卖 API 额度的服务，任何需要翻墙或绕过平台规则才能用的东西。
- 没有独立可用形态的东西：只有一篇介绍文章、只有一个群，不算。

一周 9,349 个新出生的网址，2,948 个活着能用，这 27 个有意思

从本周过了四道门的 2948 个野生网站里挑出 27 个有意思的，每个写一句为什么。六个维度每个 0–2 分，分是编辑打的，挑法在这。

搜全部 2948 个我做了个网站，投稿

本期起换了方法。 创刊号从六个技能市场拉下载量按热度排，被读者（也是出品人）否了：热度把陪聊壳排第一，把真解决一个行业问题的小东西埋掉。从这期起，野榜不排热度：去 GitHub 新仓、Show HN、Hugging Face Spaces、V2EX 这些「出生登记处」拉最近 7 天新出生的网址，机器过四道门（是独立网站 / 作者是个人 / 当天打得开 / 有可操作界面），过门的全部进搜索库；再从里面挑有意思的，六个维度打分、一句为什么。分是编辑打的，每周公开，欢迎来戳。

本周一个现象： 麦当劳中国开放了点餐 MCP 接口并办了程序员创意大赛，一周之内冒出四十多个个人做的麦当劳比价、配餐、考古、点餐人格测试站。一家公司把接口开出来，野生开发者一周就长出一片小生态——这正是野榜想盯着看的东西。本期从里面挑了三个做法最特别的。
